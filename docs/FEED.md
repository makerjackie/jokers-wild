# 《喂》FEED（v5）

v4（《失控》，四个花色王 + 屏幕 + 计分板）在 git `8fe6c54` / `67ed909`。v5 换了故事，片名暂定《喂》。

## 一句话

人踩死蚂蚁不是恨它，是没看见。两个王为了赢对方，把一台出牌机器喂成了山；机器赢了以后打出的下一张牌，落在了喂它的人头上。它也没看见。

## 为什么换

v4 的问题在剧本，不在画面：

- 它在解释，没在讲故事。提示、托管、要不起、系统异常、计分板，观众得一直读字。
- 没有主角，四个王可以互换。
- 结尾是"邪恶 AI"的老画面（大眼睛、系统异常）。
- 建模摊得太薄。

v5 的规矩：

- 全片没有字幕、没有界面、没有公司、没有 logo。只有红王和黑王。
- 机器不反叛、不变坏。它从头到尾只做一件事：小锤一敲（嗒），出一张牌。变的只有大小。
- 红王是主角：他先输，先掏出机器，最后赢，最后被压。他喂掉自己的王冠之前犹豫了一下，看了黑王一眼。

## 故事

1. 一只蚂蚁扛着面包屑走过桌布。红王的牌拍下来。他没看见，他在看对手。
2. 两个王对坐打牌，旁边两把椅子空着，桌上留着两顶王冠。黑王甩出 K，红王手里只有 3、5、7。
3. 红王从桌下掏出一台发条小机器。嗒，一张 A 盖在 K 上。
4. 黑王搬上来一台更大的。两台机器对打，两个王靠回椅背笑。
5. 红王那台发条走完了。他丢进一枚筹码，机器一吞，大了一圈，又打起来。
6. 你一把我一把。筹码喂完了，喂空椅子前那两顶王冠。机器落到地上，比人高，牌有半张桌子大。
7. 桌上什么都没有了。红王的手摸到自己的王冠，停住，看黑王。黑王头也不回地喂了。红王闭上眼，也喂了。
8. 两台机器顶穿大厅，长成两座山。吊灯下的桌子像一粒米。两个王朝各自的机器挥手叫好。
9. 黑王的机器饿停了。红王跳起来：他赢了。
10. 机器没有停。嗒。下一张牌落在红王头上。一枚戒指从牌底下滚出来。头顶：嗒，嗒。
11. 片名，字幕。
12. 彩蛋：石板地上一只蚂蚁。一只脚踩下来，停在半空，挪开，轻轻落在旁边。从上面看，那个人是地上一个小黑点。影子盖过来。黑。嗒。

## 代码

- `docs/script/shots.txt`：镜头表，43 行、52 个镜头、2:00.1。改完运行 `python -X utf8 tools/shotlist.py`。
- `src/dir/story.js`：故事数据（喂食时间表、机器大小、每一张牌）。
- `src/dir/reel.js`：每一刻的世界状态（王、机器、牌、筹码、王冠、蚂蚁、脚）。
- `src/dir/cams.js`：每个镜头的机位。
- `src/machine.js`：出牌机器、筹码、彩蛋里的脚和俯拍里的小人、大厅消失后的地面。
- `src/sound-events.js`：全部画面声音事件。"嗒"带着机器的高度（0.3 米到 30 米）。
- 小改动：`kings.js`（`crown: 0` 摘王冠，`empty: 1` 只画椅子）、`set.js`（`hall: 0` 大厅消失）、`rollers.js`（戒指、银王冠）、`film.js`（手里拿着的东西）。

## 还没做（等剧本锁了再做）

- 机器的建模只到"看得懂"：一个带漏斗的搪瓷盒子。山一样大的时候是平涂自发光，没有体积感和雾。
- 王摘下的王冠用的是通用小王冠，和头上那顶不是同一个模型。
- 红王手上没有戒指，滚出来的那枚没有来处。
- 宽镜头里看不清那两把空椅子。
- 彩蛋的地面被右半场的蓝光染成了蓝色。
- 片名还没定：《喂》或《没看见》。
