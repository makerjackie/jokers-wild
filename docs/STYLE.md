## 1. 三种画风

三种画风用的是同一套模型、同一盏灯、同一个镜头，只换渲染。所以选哪种都不用返工建模和动画。

| | A 黑色战情室（推荐） | B 刮版版画 | C 冷战海报 |
|---|---|---|---|
| 一句话 | 一盏灯、烟、硬阴影；世界是暖色单色调，只有牌是彩色的 | 国王像从黑底上刻出来的铜版画，牌是手工上色 | 两色丝网印：中方半边红、美方半边蓝、中线黑，半调网点 |
| 好处 | 最紧张；"AI 是这个世界里唯一有颜色的东西"本身就是全片的隐喻，越往后彩色越多 | 最像一幅会动的政治讽刺画，十九世纪漫画的血统 | 最直白：一眼看出中美两边；做海报和封面最抢眼 |
| 风险 | 暗，手机上要保证脸看得清 | 线条细，压缩后会糊；整体偏暗 | 太像宣传画，政治味重；红蓝对立在国内平台更敏感 |

## 2. 角色和世界

- **国王**：十位坐着的宫廷牌国王，雕像一样的硬壳长袍、貂皮领、链子和公司徽章、各不相同的王冠（OpenAI 六角高冠、Claude 叶冠、Google 四色宝石冠、xAI 尖刺冠、Meta 圆珠冠、DeepSeek 鳍冠、千问城垛冠、Kimi 拱冠带新月、智谱尖冠、豆包圆顶冠），王冠正面是公司 logo。脸是画上去的宫廷牌脸：杏仁眼、长鼻、卷胡子，胡子是雕出来的。
- **牌**：模型牌（logo、型号、角上的跑分）、两边的牌背（中方红底金纹、美方蓝底银纹）、托管之后的"机器文字"牌（黑底金色符号）、两张各半张脸的王（并排时拼成一张笑脸）。
- **战情室**：长桌、海图桌布（两块抽象大陆，没有国界）、吊灯、空王座、两侧玻璃柜、翻牌记分板。

## 3. 基调样片（2:00–2:28）

从 Claude 国王盯着托管键开始，到两张王升起为止：按键 → 全桌连锁按键 → 胳膊被发光的线吊着自己出牌 → 点雪茄、隔海举杯 → 从玻璃柜里往外看 → 白闪、玻璃裂 → 进行曲卡顿、定格、衰减 → 警报 → 取消键按了十几下 → 国印被牌吊住 → 两张王升起。

配乐（全部用 JavaScript 合成，没有采样；细节见 [SOUND.md](SOUND.md)）：

- **按托管**：低音提琴和大提琴压一个低 D 的持续音；前三位国王按键时，长号和大号把国王动机（D、降 E、E 三个音半音上行）紧张地吹一遍；之后每多一位国王按下，弦乐簇就多一个半音，按键的继电器声就是节奏，每一声配一记战鼓。
- **讽刺进行曲**：从点雪茄那一刀进来。原创曲调，降 B 大调 2/4 拍，铜管乐队，像从战情室的喇叭里放出来的（窄频、略带破音、石头房间的大混响），太响、动态很平。中间转酸：第 6 小节歪到降 G 大调，第 7 小节沉进降 e 小调，第 8 小节全队齐奏国王动机，最强音正好落在玻璃裂的那一拍。
- **崩坏**：玻璃裂之后进行曲像 CD 跳针一样重复 5 次，定格在一个降 B 上，再变暗、衰减到几乎无声。
- **洞**：只剩机房嗡鸣、玻璃慢慢裂开的声音、远处的牌声。
- **警报**：低沉的双转子防空警报，约 3 秒一起一落；取消键的十几下是干的，没有混响。
- **结尾**：国印落下时低铜管下行四个音，被牌暴和铁链声吞掉；最后一段低音弦乐颤音簇半音半音往上爬，在最后一帧连同警报和牌暴一起被切断。
- 牌的"滴答"从第一秒到最后一秒都在：按键时八分音符，狂欢时十六分，玻璃裂之后放慢、变轻，在寂静里继续走。
- 实测：峰值 −1 dBTP，无削波、无爆音；狂欢段约 −10 LUFS，"洞"约 −42 LUFS。

## 4. 还粗糙的地方（选定画风后进入制作时处理）

- **国王的脸**：现在像刻出来的面具，表情变化少，嘴常被胡子挡住；特写里还要加强眼神。
- **手**：是简单的铁手套，快速伸手时会"跳"一下。近景里尽量不拍手，这条在剧本阶段就定了。
- **偏暗**：黑色战情室在手机上可能太暗，大远景要再提一点亮度。
- **合成铜管**：长音和圆号的后半拍最容易露出"合成味"，可能被听成滑稽的"嘭嚓"。
- **版画风格**：暗部是深灰而不是纯黑，细线压缩后容易糊。
- **海报风格**：红蓝按左右半边分，国王一探身越过中线就会变色。
- **牌暴**：现在是匀速旋涡，缺少成团、成流的形态；托管后飞来飞去的牌偏多。
- **国印**（2:24）：被牌暴挡住、又背光，在样片里几乎看不清，要给它们打一束光。
- **狂欢蒙太奇**：有两三个特写里举杯的胳膊会挡到脸，太快了不一定看得出来，但要重排机位。
- 这一段之外的镜头还没有做，片子里其余部分目前只有机房嗡鸣。
