## 这部片子是什么

AI 公司的国王们围坐一张长桌出"模型牌"，谁的牌更强谁就是第一。出牌倒计时越来越短，每块屏幕上弹出一句客气的话："Too slow? Let AI play for you." 不肯托管的人因为太慢被淘汰；按了托管的人发现，取消键再也没有反应。

全片没有对白，没有中文字幕需求，海外和国内用同一个视频文件。

制作事实（可直接引用）：

- 编剧：MakerJackie（人类）。导演、动画、配乐、音效、剪辑：Claude（由 Fable 5.2 主导，部分环节由 Claude Opus 5.5 协助）。
- 全片由代码生成：three.js 渲染，配乐和音效用 JavaScript 合成。约 2.3 万行代码，82 个镜头，3,895 帧。
- 没有使用任何图像、视频、音频生成模型，没有任何图片、视频、音频素材文件。
- 从第一版剧本到成片 7 天，共 22 个版本。
