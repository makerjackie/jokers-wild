# A prompt for making your own pure-code short with Claude Code

Copy this into Claude Code in an empty folder, fill in the 【】 parts, and let it run. It is the process that made 《王炸 / JOKERS WILD》.

```
Make a 2–4 minute animated short, 100% in code: three.js for every frame, JavaScript synthesis for every sound,
no image/video/audio models, no asset files. The whole film must play offline from one HTML file.

Subject: 【your subject in one paragraph: what it is about, the tone, the ending】

Process (show me the result of each step before the next):
1. Research the subject and 2–3 reference films; list the 4–5 real dynamics the film must show.
2. Three directions in one page each; I pick one.
3. The script: one-line pitch, characters, beats, a shot list with timecodes (keep it in a text source file that a
   tool turns into a table and a tension chart), music cues, loudness walls and holes, where every gag comes from.
4. Style frames in 2–3 looks plus a 20–30 s scored tone reel. I must see and hear it before production.
5. Production in parallel: you are the director (every shot, integration); give set, props, characters, the big
   set piece and sound to separate agents with written contracts (state fields, coordinates, file ownership).
6. Quality rounds: contact sheet of every shot, full-resolution checks of key frames, an automated scan for frames
   that jump, a full low-resolution preview after each round. Fix what you find; repeat at least twice.
7. Release: 1080p render, covers in 6 sizes (zh/en) rendered from the film with code-drawn titles, copy for each
   platform, README, PLAYBOOK (what broke), and a publishing dry-run I approve before anything is posted.

Rules: every frame is a pure function of time (no Math.random, no Date); derive sound events from the same data as
the picture; every company or side is treated the same; show me images and video, not just "fixed".
```
